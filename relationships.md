# Relationship Framework

A title does not need to literally represent the anchor text.

A strong title has a **meaningful semantic relationship** with the anchor — not just a repetition of its words.

There are four relationship types available:

---

## 1. Direct Relationship

### Definition

A title has a **Direct Relationship** when it explicitly addresses the same subject, entity, product, service, activity, problem, process, or search intent as the anchor text.

The title may use different words, but its primary subject remains the same.

### Formula

```
Anchor
  ↓
same subject / entity / intent
  ↓
Title
```

### Examples

**Anchor Text:**
```
Adidas Adizero Evo SL
```

**Title:**
```
5 Kelebihan yang Ditawarkan Adidas Adizero Evo SL
```

Relationship: same product → product advantages → **Direct**

---

**Anchor Text:**
```
cara daftar paspor online
```

**Title:**
```
5 Hal yang Perlu Disiapkan Sebelum Daftar Paspor Secara Online
```

Relationship: same process → preparation steps → **Direct**

---

**Anchor Text:**
```
harga Honda Beat
```

**Title:**
```
5 Hal yang Perlu Diketahui Sebelum Membeli Honda Beat
```

Relationship: same product → purchase decision → **Direct**

Note: the title does not need to repeat the word "harga" to remain Direct.

---

**Anchor Text:**
```
sepatu running wanita
```

**Title:**
```
7 Tips Memilih Sepatu Running Wanita untuk Olahraga Harian
```

Relationship: same product category → selection guide → **Direct**

---

## 2. Contextual Relationship

### Definition

A title has a **Contextual Relationship** when it does not directly address the anchor subject, but maintains a meaningful connection through:

- user journey
- use case
- audience need
- destination or goal
- adjacent topic
- related entity
- related activity
- related problem or benefit
- broader topic cluster

Contextual relationships must be **meaningful and logically explainable** — not merely vague topical proximity.

### Formula

```
Anchor
  ↓
context / journey / use case / related entity
  ↓
different but meaningfully connected topic
  ↓
Title
```

### Examples

**Anchor Text:**
```
tiket pesawat Jakarta-Palembang
```

**Title:**
```
7 Destinasi Wisata di Kota-Kota Sekitar Palembang yang Bisa Anda Kunjungi
```

Relationship:
```
airline ticket → travel → Palembang → tourism → destinations
```

Explanation: someone buying a ticket to Palembang is naturally interested in what to do there. → **Contextual**

---

**Anchor Text:**
```
kredit rumah KPR
```

**Title:**
```
5 Biaya Renovasi Rumah yang Sering Membengkak Tiba-Tiba
```

Relationship:
```
KPR → home ownership → house → renovation → renovation costs
```

→ **Contextual**

---

**Anchor Text:**
```
hotel murah Bandung
```

**Title:**
```
5 Tempat Wisata Bandung untuk Liburan Hemat
```

Relationship:
```
hotel → accommodation → travel → Bandung → tourism
```

→ **Contextual**

---

**Anchor Text:**
```
kartu kredit cashback
```

**Title:**
```
7 Cara Mengatur Pengeluaran agar Tidak Boncos Setiap Bulan
```

Relationship:
```
credit card → spending → personal finance management → budgeting
```

→ **Contextual**

---

### Contextual Relationship Strength Levels

| Strength | Example (Anchor: tiket pesawat Jakarta-Palembang) |
|---|---|
| **Strong** | 7 Destinasi Wisata di Kota-Kota Sekitar Palembang |
| **Moderate** | 5 Tips Menyiapkan Liburan Singkat ke Palembang |
| **Weak** | 7 Makanan Khas Palembang yang Wajib Dicoba |

Use only strong or moderate relationships.

Do not force a weak or unrelated topic into the Contextual category.

---

## 3. Negative / Adverse Relationship

### Definition

A title has a **Negative / Adverse Relationship** when it explores a negative condition associated with the anchor subject, such as:

- mistakes
- risks
- losses
- drawbacks
- failures
- problems
- adverse effects
- negative consequences
- things to avoid

The title may directly address the anchor subject or shift to its negative outcomes.

### Examples

**Anchor Text:**
```
investasi saham pemula
```

**Title:**
```
7 Kesalahan Fatal Investasi Saham Pemula yang Bikin Buntung
```

→ **Direct + Negative**

---

**Anchor Text:**
```
konsumsi gula harian
```

**Title:**
```
Dampak Buruk Kelebihan Konsumsi Gula Harian bagi Kesehatan Ginjal
```

→ **Direct + Negative**

---

**Anchor Text:**
```
perawatan mobil rutin
```

**Title:**
```
7 Masalah yang Bisa Muncul Jika Mobil Jarang Diservis
```

→ **Contextual + Negative**

The title focuses on the negative consequence rather than explaining routine maintenance directly.

---

### Negative Framing Boundary

Negative framing may be strong, but must remain supportable by the article.

| | Example |
|---|---|
| **Safe** | 5 Kesalahan yang Bisa Membuat Pengeluaran Bulanan Membengkak |
| **Potentially problematic** | 5 Kesalahan Fatal yang Pasti Menghancurkan Keuangan Anda |

Avoid absolute or exaggerated consequences unless genuinely supported by the article content.

---

## 4. Causal Relationship

### Definition

A title has a **Causal Relationship** when it focuses on an effect, consequence, mechanism, result, or process that is caused by, produced by, or meaningfully explained by the anchor subject.

### Formula

```
Anchor (cause)
  ↓
effect / consequence / mechanism / outcome
  ↓
Title
```

### Examples

**Anchor Text:**
```
pola makan tinggi garam
```

**Title:**
```
Mengapa Tekanan Darah Anda Naik? Ini Mekanisme Tubuh Saat Memproses Natrium
```

→ **Causal**

---

**Anchor Text:**
```
kurang tidur
```

**Title:**
```
Mengapa Sulit Berkonsentrasi Setelah Kurang Tidur?
```

Relationship:
```
kurang tidur → gangguan konsentrasi
```

→ **Causal**

---

**Anchor Text:**
```
perawatan mobil rutin
```

**Title:**
```
Apa yang Terjadi Jika Mobil Jarang Diservis?
```

→ **Causal + Negative**

---

## Relationship Combinations

Relationships are not mutually exclusive. A single title may carry more than one label.

| Combination | Example |
|---|---|
| **Direct + Negative** | 7 Kesalahan Fatal Investasi Saham Pemula yang Bikin Buntung |
| **Direct + Causal** | 5 Dampak Konsumsi Gula Berlebih terhadap Tubuh |
| **Contextual + Negative** | 5 Biaya Renovasi Rumah yang Sering Membengkak Tiba-Tiba |
| **Contextual + Causal** | Mengapa Cicilan Rumah Bisa Terasa Berat? |
| **Negative + Causal** | Mengapa Konsumsi Garam Berlebih Dapat Meningkatkan Tekanan Darah? |

---

## Decision Rule: Direct vs Contextual

### Use Direct when:

> "Does this title address the same subject, entity, or intent as the anchor?"

If yes → **Direct**

### Use Contextual when:

> "Does this title address a different immediate subject that is nevertheless meaningfully connected through a real user journey, use case, audience need, or topic relationship?"

If yes → **Contextual**

Do not force Contextual when the relationship is only superficial.

### Direct is not automatically better than Contextual

A Contextual title may be preferable when:
- it produces a more natural editorial topic
- it avoids keyword-heavy titles
- it better matches the brief or soft-selling objective
- it creates a more useful downstream article

---

## Relationship Matrix

| Relationship | Primary Question |
|---|---|
| Direct | Does the title address the same subject, entity, or intent? |
| Contextual | Is the title meaningfully connected through context, journey, use case, or a related need? |
| Negative / Adverse | Does the title explore risks, failures, drawbacks, losses, or adverse outcomes? |
| Causal | Does the title explain an effect, mechanism, consequence, or outcome? |
